ℹ️ About Time Zones

This converter uses the browser's Intl.DateTimeFormat API and IANA timezone database.

Daylight Saving Time is handled automatically. For example, selecting America/New_York will automatically display EST or EDT depending on the selected date.

You should therefore select a regional timezone such as Eastern Time (ET) rather than creating separate EST and EDT timezone entries.
